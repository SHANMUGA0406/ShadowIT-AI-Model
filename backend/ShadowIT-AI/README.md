# Explainable AI-Based Shadow IT Detection and Decision Intelligence Platform

## Project Overview
This project is a prototype developed for Smart India Hackathon (SIH) 2026.

It detects Shadow IT devices in a network using Nmap, classifies device risk using Machine Learning, explains AI decisions using SHAP, analyzes possible cyber impacts, and recommends security actions.

## Technologies Used

- Python
- FastAPI
- Nmap
- Random Forest
- SHAP
- Scikit-learn
- Pandas

## Features

- Network Device Discovery
- Shadow IT Detection
- AI Risk Classification
- Explainable AI (SHAP)
- Cyber Impact Analysis
- Decision Support Engine
- FastAPI REST APIs

## API Endpoints

- POST /scan
- GET /devices
- GET /device/{id}
- GET /dashboard
